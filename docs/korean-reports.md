# 한국형 보고서 (공공기관 보고 양식)

MAKUS vLAB 1.2.0 부터 **보고서 탭 > 공공 보고서**에서 공공기관 보고 양식의 가상화 인프라 보고서를 만듭니다.
MAKUS vLAB 한국형 보고서를 MAKUS vLAB 로 이식한 기능입니다.

## 보고서 3종

| 보고서 | 내용 |
|---|---|
| 가상화 인프라 운영 현황 보고 | 기간 중 운영 요약(종합 판정), 노드 가동·자원 사용률(평균·최대), 스토리지 사용률, 백업 성공·실패, **하드웨어(BMC) 상태 이력**, 조치가 필요한 항목 |
| 자원 사용 현황 및 증설 검토 | 노드·스토리지별 사용률과 기준(주의 80%·위험 90%) 대비 판정, 증설 검토 의견 |
| 가상서버 자원 현황 대장 | 가상서버·컨테이너 전체 목록(클러스터·노드·vCPU·메모리·디스크·상태·태그) — 기간과 관계없이 생성 시점 현황 |

## 사용 방법

1. 클러스터를 고르고 **보고서 → 공공 보고서**
2. 보고서 종류, 보고 기간(이번 달·지난 달·최근 7일·최근 30일·지난 분기·올해 또는 직접 입력), 대상 클러스터(기본은 지금 클러스터, '전체' 가능)
3. 작성 정보(기관명·부서명·작성자·연락처·보안 등급 표시) — 선택, 이 브라우저에 기억
4. 오른쪽 미리보기가 조건을 바꿀 때마다 자동으로 갱신
5. 내려받기
   - **PDF**: 인쇄 창에서 '대상 → PDF로 저장' (파일 이름은 보고서 제목)
   - **한글(HWPX)**: 한글 2014 이후에서 열림. HWP 가 필요하면 한글에서 '다른 이름으로 저장 → HWP'
   - **워드(DOCX)**, **엑셀(XLSX)**: 엑셀은 표마다 시트, 숫자는 계산할 수 있는 값

## 자료와 권한

- 자료: Proxmox VE API — `/cluster/resources`·`/cluster/status`(구성·현재 상태), 노드 `/rrddata`(AVERAGE·MAX) 중 보고 기간 값의 평균·최대, 노드 `/tasks`(vzdump, 보고 기간)
- 사용률은 Proxmox 의 RRD 보관 단위(일·주·월·연)를 보고 기간에 맞춰 고릅니다. 오래된 기간일수록 값이 거칠어집니다.
- 권한: **노드 조회(node.view)**, 볼 수 있는 클러스터만, 가상서버는 VM 조회 권한(ACL)이 있는 것만
- 읽지 못한 클러스터는 미리보기 아래에 따로 표시하고 나머지로 보고서를 만듭니다.
- **하드웨어(BMC) 상태 이력** (운영 현황 보고서): 하드웨어 모니터링(설정의 동의)을 켜면 5분마다 노드 하드웨어 상태를 읽는데
  (노드 안 ipmitool 우선, 안 되면 등록한 Redfish BMC), 상태가 **바뀐 순간**(발생·등급 상승·복구)을 기록합니다 (`pegaprox/core/hw_history.py`, 표 `hw_state`·`hw_events`, 400일 보관).
  보고서에는 보고 기간 중 이상과 발생·복구 시각·횟수, 기간 전부터 이어진 이상, 기간 말 미복구 건이 들어갑니다.
  기간에 지금이 들어 있으면(이번 달 등) 현재 상태 열도 붙습니다. 기록이 시작되기 전 기간은 '기록 없음'으로 표시합니다.
  읽지 못한 회차(SSH·BMC 일시 오류)는 상태를 바꾸지 않아 '복구'가 잘못 찍히지 않습니다.
- 문서 파일은 **브라우저에서** 만듭니다 (서버는 자료만 보냄, 외부 라이브러리·인터넷 연결 불필요 — 격리망 그대로 사용)

## 구성 (개발자용)

| 파일 | 역할 |
|---|---|
| `pegaprox/api/korean_reports.py` | 자료 수집 API — `GET /api/korean-reports/clusters`, `POST /api/korean-reports/data` |
| `web/src/korean_reports.js` | 화면 (보고서 탭의 '공공 보고서' 하위 탭) |
| `web/reports-src/` | 보고서 양식(`html.js`)과 한글·워드·엑셀 변환(`hwpx.ts`·`docx.ts`·`xlsx.ts`) 원본 |
| `static/js/makus-reports.js` | 위 원본을 묶은 결과 (`window.MakusReports`) — 화면이 필요할 때 불러옴 |
| `pegaprox/core/hw_history.py` | 하드웨어 상태 이력 — 상태 변화 기록(`background/metrics.py` 의 5분 수집이 호출), 보고 기간 이상 계산 |
| `tests/test_korean_reports.py`, `tests/test_hw_history.py` | API 통합 테스트(보고서 종류·기간·입력 오류·권한·실패한 클러스터·하드웨어 이력), 이력 규칙 테스트 |

양식·변환을 고친 뒤:

```bash
bash web/reports-src/build.sh   # static/js/makus-reports.js 다시 만들기 (Node.js 18+)
bash web/Dev/build.sh           # 화면(web/index.html) 다시 만들기
```

두 결과 파일도 함께 커밋합니다 (설치본은 빌드 없이 그대로 씀).
